Local history connector

This extension can read Chrome browsing history only after Chrome grants the History permission. The dashboard must also request an analysis session.

What it readsPage titles, URL paths, and visit times from the period you select. Query strings and fragments are removed.Where it sends recordsOnly to the dashboard tab on the approved origin. Data remains in that tab's memory.What it never readsPasswords, cookies, tokens, page contents, or protected credentials.
No records are retained by the extension.Manage or remove this extension in Chrome
